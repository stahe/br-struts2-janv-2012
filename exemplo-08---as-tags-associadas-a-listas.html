    10. Exemplo 08 – As tags associadas a listas

    O exemplo a seguir aborda as tags que exibem listas. Já as vimos no exemplo anterior: a lista suspensa, as caixas de seleção e os botões de opção. O formulário de teste será o seguinte:

    10.1. O projeto NetBeans

    O projeto do NetBeans é o seguinte:

    • em [1] a ação e em [2] a visualização associada.

    O arquivo [example/example.xml] configura o aplicativo:

    
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE struts PUBLIC
        "-//Apache Software Foundation//DTD Struts Configuration 2.0//EN"
        "http://struts.apache.org/dtds/struts-2.0.dtd">

<struts>
  <package name="example" namespace="/example" extends="struts-default">
    <action name="Form" class="example.Form">
      <result name="success">/example/Form.JSP</result>
    </action>
  </package>
</struts>

    As linhas 8-9 mostram que uma chamada à ação URL gera a visualização [/example/Form.action]. A ação [Form] será, portanto, responsável por construir o modelo da visualização [Form.JSP].

    Vamos examinar os diferentes elementos de entrada do formulário:

    • linha 27: a tag <s:select>: 
    
      <s:select name="select1" list="{'vert','jaune','rouge'}" size="1" key="Form.select1"/>

    Essa tag gerará o seguinte código HTML:

    1
2
3
4
5
    <select name="select1" size="1" id="Form_select1">
    <option value="vert">vert</option>
    <option value="jaune" selected="selected">jaune</option>
    <option value="rouge">rouge</option>
</select>

    O valor do atributo list é uma matriz de cadeias de caracteres usada para gerar os valores e os rótulos das opções. O modelo associado é o campo select1 da ação [Form] a seguir:

    
  private String select1 = "jaune";

    Esse campo está associado, tanto para leitura quanto para gravação, à tag denominada select1. Na gravação, o valor da opção selecionada será inserido no campo select1. Na leitura, o valor do campo select1 serve para determinar a opção selecionada. Aqui, o valor jaune do campo select1 serve para selecionar a opção da tag select1, que tem o valor “amarelo”. É por isso que, na linha 3, a opção está selecionada.

    • linha 28 
    
<s:select name="select2" list="{'vert','jaune','rouge'}" size="3" key="Form.select2" multiple="true"/>

    Não há diferença fundamental em relação à tag da linha 27, exceto que, neste caso, a seleção é múltipla. Portanto, o valor enviado é uma matriz de valores, correspondente às opções selecionadas. O campo select2 da ação associada ao formulário é o seguinte:

    
  private String[] select2 = new String[]{"vert", "rouge"};

    Trata-se, de fato, de uma matriz. Seu valor inicial serve para selecionar as opções cujos valores estão presentes na matriz.

    • linha 29 
    
      <s:select name="select3" list="#{'01':'vert(01)','02':'jaune(02)','03':'rouge(03)','04':'blanc(04)','05':'noir(05)'}" size="3" key="Form.select3" multiple="true"/>

    Aqui, o valor do atributo list é um dicionário cujas chaves servem como valores para as opções e os valores associados servem como rótulos para as opções. O código HTML gerado é o seguinte:

    <option value="04">blanc(04)</option>

    O campo associado na ação é o seguinte:

    
  private String[] select3 = new String[]{"01", "03"};

    Temos novamente uma tabela de valores, pois a tag associada é de múltipla escolha. Os valores iniciais da tabela explicam por que as opções das linhas 2 e 4 estão inicialmente selecionadas.

    • linha 30 
    
      <s:select name="select4" list="dico" size="3" key="Form.select4" multiple="true"/>

    Aqui, as opções da lista serão fornecidas pelo modelo da visualização, modelo que, neste caso, faz parte da ação [Form]:

    
private HashMap<String, String> dico = new HashMap<String, String>();

    As chaves do dicionário dico serão os valores das opções. Os valores do dicionário dico serão os nomes das opções. O campo select4 da ação é o seguinte:

    
  private String[] select4 = new String[]{"1", "3"};

    Trata-se de uma tabela de valores que receberá os valores enviados pela tag select4.

    • linha 31 
    
<s:select name="select5" list="couleurs" listKey="id" listValue="nom" size="3" key="Form.select5" multiple="true" />

    A lista de opções é gerada pelo campo couleurs, definido pelo atributo list. O campo couleurs da ação [Form] está definido da seguinte forma:

    
private Couleur[] couleurs;

    A classe [Couleur] é definida da seguinte forma:

    
package example;

public class Couleur {

  // campos
  private String id;
  private String nom;

  // construtor
  public Couleur(){
  }

  // getters e setters
...  
}

    Ela possui dois campos chamados id e nom. Na tag select5, temos listKey="id" e listValue="nom".. Isso significa que o campo id servirá como valor para uma opção e o campo nom servirá como descrição. Vale lembrar que são os valores das opções que são lançados. Eles serão lançados no campo select5 a seguir:

    
  private String[] select5 = new String[]{"1", "3"};

<s:checkboxlist name="checkboxlist1" list="#{'01':'vert(01)','02':'jaune(02)','03':'rouge(03)','04':'blanc(04)','05':'noir(05)'}" key="Form.checkboxlist1"/>

// valores selecionados em listas suspensas
  public String getSelect2SelectedValues() {
    return getArrayValue(select2);
  }

  // métodos utilitários

    10.4. A ação [Form]

    Ao comentar a visualização [Form.JSP], apresentamos os campos da ação [Form] associada. O código da ação [Form] é o seguinte:

    
package example;

import com.opensymphony.xwork2.ActionSupport;
import java.util.HashMap;

public class Form extends ActionSupport {

  // campos do formulário
  private String select1 = "jaune";
  private String[] select2 = new String[]{"vert", "rouge"};
  private String[] select3 = new String[]{"01", "03"};
  private String[] select4 = new String[]{"1", "3"};
  private String[] select5 = new String[]{"1", "3"};
  private HashMap<String, String> dico = new HashMap<String, String>();
  private Couleur[] couleurs;
  private String[] checkboxlist1 = new String[]{"01", "03"};
  private String[] checkboxlist2 = new String[]{"1", "3"};
  private String[] checkboxlist3 = new String[]{"1", "3"};
  private String radio1="01";
  private String radio2="1";
  private String radio3="1";

  private String submitText;

  // construtor sem parâmetro
  public Form() {
    // inicialização do dicionário de cores
    dico.put("1", "vert(1)");
    dico.put("2", "jaune(2)");
    dico.put("3", "bleu(3)");
    dico.put("4", "rouge(4)");
    dico.put("5", "blanc(5)");

    // inicialização da matriz de objetos Cor
    couleurs = new Couleur[dico.size()];
    int i = 0;
    for (String key : dico.keySet()) {
      couleurs[i] = new Couleur();
      couleurs[i].setId(key);
      couleurs[i].setNom(dico.get(key));
      i++;
    }
  }

  // valores selecionados em listas suspensas
  public String getSelect2SelectedValues() {
    return getArrayValue(select2);
  }

  public String getSelect3SelectedValues() {
    return getArrayValue(select3);
  }

  public String getSelect4SelectedValues() {
    return getArrayValue(select4);
  }

  public String getSelect5SelectedValues() {
    return getArrayValue(select5);
  }

  public String getCheckboxlist1SelectedValues() {
    return getArrayValue(checkboxlist1);
  }

  public String getCheckboxlist2SelectedValues() {
    return getArrayValue(checkboxlist2);
  }
  public String getCheckboxlist3SelectedValues() {
    return getArrayValue(checkboxlist3);
  }

  // métodos utilitários
  public String getArrayValue(String[] values) {
    String result = "";
    for (String value : values) {
      result += " " + value;
    }
    return result;
  }

  // getters e setters
   ...
}

    Não há nenhum método execute nessa ação. Portanto, é o método execute da classe pai ActionSupport que é executado. Esse método não realiza nenhuma ação e se limita a retornar a chave de navegação SUCCESS.

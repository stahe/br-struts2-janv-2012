    19. Estudo de caso – versão 1

    19.1. A camada [metier] simulada

    Voltemos à arquitetura do aplicativo que estamos construindo:

    Temos o arquivo das camadas [metier, dao, jpa] e apresentamos os elementos dessas camadas que a camada [web] deveria conhecer. Estamos prontos para escrever essa camada usando o framework Struts.

    Para simplificar os testes de nossa aplicação em desenvolvimento, vamos criar uma camada de negócios simulada que respeitará a interface da camada [metier]. A arquitetura ficará da seguinte forma:

    Vamos desenvolver a camada [web] com a camada [métier] simulada. Os testes serão mais simples de realizar, pois não há mais banco de dados na arquitetura. Graças ao Spring e ao uso de interfaces, substituir posteriormente a camada simulada [metier] pela arquitetura real [metier, dao, jpa] não terá nenhum impacto no código da camada [web / struts2]. A camada [web / struts2] que vamos desenvolver agora poderá ser utilizada tal como está.

...
public class Supprimer extends ActionSupport implements SessionAware {

  // sessão
  private Map<String, Object> session;
  // ID da simulação a ser excluída
  private String id;
  // menu
  private Menu menu;

  @Override
  public void setSession(Map<String, Object> session) {
    this.session = session;
  }

  // execução da ação
  public String execute() {
    // recuperação das simulações na sessão
    List<Simulation> simulations = (List<Simulation>) session.get("simulations");
    if (simulations == null) {
      // situação anormal — a sessão deve ter expirado
      menu = new Menu(false, false, false, false, true, true);
      return "erreur";
    }
    // teste de ID
    int num = 0;
    boolean erreur = false;
    try {
      num = Integer.parseInt(id);
      erreur = num <= 0;
    } catch (NumberFormatException ex) {
      // anormal
      erreur = true;
    }
    // erro?
    if (erreur) {
      menu = new Menu(false, false, false, false, true, true);
      return "erreur";
    }
    // procurando a simulação a ser excluída
    for (int i = 0; i < simulations.size(); i++) {
      if (num == simulations.get(i).getNum()) {
        simulations.remove(i);
        break;
      }
    }
    // exibindo a lista de simulações
    menu = new Menu(false, false, false, false, true, true);
    return "simulations";
  }

  // getters e setters
...
}
